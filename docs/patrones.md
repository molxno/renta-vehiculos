# Patrones GoF en el MVP

Cinco patrones con una necesidad real en el flujo de reserva, devolución y
pago. Strategy, State y Adapter no se solapan: cada uno cubre una variación
distinta. Factory Method e Observer se suman sin reemplazarlos.
